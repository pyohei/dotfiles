## Install

Copies `.local/bin` into `~/.local/bin`, and the AI instruction files
into `~/.claude` and `~/.codex`.

```sh
./install.sh -n   # dry run
./install.sh
```

Files this repository no longer tracks are left in place and have to be
removed by hand.
